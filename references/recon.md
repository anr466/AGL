# فهم المشروع قبل اللمس (`recon.py`)

الحلقة 2 في المهارة. الهدف: لا تعدّل مشروعاً لا تعرف كيف يُشغَّل ويُختبَر ويُسمّي أشياءه.

```
python <المهارة>/recon.py scan            # يكتب .agl/recon.json ويطبع الملخص
python <المهارة>/recon.py search كلمات…    # هل هذا موجود أصلاً؟ (قبل أن تبني)
python <المهارة>/recon.py check           # exit 2 إن بقي مجهول حرج (أمر اختبار/تشغيل/لغة)
```

## ما يستخرجه
اللغات والملفات الوصفية · أوامر الاختبار والتشغيل (`scripts`، README، pytest) · متغيرات البيئة الموثقة وغير الموثقة · المنافذ · أسطح المشروع (واجهة/API/CLI → تحدد نوع عقد عين المستخدم) · نقاط الدخول · ملفات القواعد (`AGENTS.md`, `CLAUDE.md`…، تسبق المهارة) · حالة git · أسماء مكررة.

## كل واقعة بنوعها
- `documented`: قُرئت الآن من ملف مذكور.
- `inferred`: استنتاج من قرائن — تُذكر بصيغة «يُرجّح»، ولا تُبنى عليها خطوة لا رجعة فيها قبل التحقق.
- ما لم يُعثر عليه يظهر في `unknowns` (حرج أو لا). **المجهول الحرج يُسأل عنه المستخدم ولا يُخمَّن.**

## حدودها
تجمع وقائع ولا تفهم المعنى: لا تعرف لماذا صُمّم شيء بطريقة ما. بعد المسح اقرأ الملفات التي ستلمسها بنفسك (القانون 1: الحقيقة في الكود). عمل غير محفوظ في git يُفترض للمستخدم ولا يُلمس.
