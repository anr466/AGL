# البوابات — مرجع الأوامر (`gates.py`, `jobs.py`, hook)

كل أمر يُنفَّذ من مجلد المهارة: `python <مسار المهارة>/gates.py ...`. رمز الخروج 0 = مسموح/ناجح، 1 = مرفوض.
الحالة تُحفظ في `.agl/` (أو `AGL_STATE_DIR`) ولا تُرفع إلى git.

| الأمر | متى | ما يفعله |
|---|---|---|
| `verify --label L --expected N --actual M --stored V --visible yes\|ux --timestamp T [--max-age S]` | قبل أي ادعاء «تم» | قراءة عكسية: العدّاد يطابق، القيمة مخزنة (0/false مقبولة كبيانات؛ فارغ/none/خطأ لا)، الحالة مرئية، الطابع الزمني حديث (لا قديم ولا من المستقبل). `--visible ux` يشتق الرؤية من آخر `ux_gate.py gate` بنتيجة PASS حديثة على أدلة لم تتغير |
| `classify <نوع> <أين> <ماذا>` | عند كل فشل | النوع: افتراض / تنفيذ / فهم / بيئة، والمجهول مرفوض. يعيد بروتوكول النوع |
| `stop --sig "<ما جُرّب>" --err "<الرسالة>" [--diff "<وصف الفرق>"] [--reset]` | بعد كل مسار فاشل | يسجّل المسار في `.agl/stop.json`. المسار شبه المكرر يُرفض (غيّر النهج فعلاً)، و3 مسارات مختلفة = توقف وصعود |
| `git "<أمر git>"` | قبل أمر git | نفس الحارس مقصوراً على git |
| `shell "<أمر>" [--approved]` | قبل أمر شل حساس | تحليل شلّي (لا نصي): يرفض الكتابة على التاريخ والحذف غير المسجَّل؛ الموافقة (`--approved`) تفتح العادي لا النهائي (`rm -rf /`, `~`, جذر المشروع) |
| `files register <مسار>` ثم `check` / `list` | قبل إنشاء ملف تجريبي | الحذف مسموح لما سجّلته أنت فقط (ولم يُتتبّع في git). مخازن الأدوات المؤقتة (`__pycache__`, `.pytest_cache`…) تُحذف بلا تسجيل |

## مهام الخلفية (`jobs.py`)
`start "<أمر>" [--timeout S]` يعود فوراً بمعرّف، و`status|result|tail|wait|cancel|list`. الحارس نفسه يسري على أوامر الخلفية. مهام POSIX فقط.

## خطّاف Claude Code (`hook_pretooluse.py`)
يفرض الحراس إلزامياً: «اسأل المستخدم» للكتابة على التاريخ، و«ارفض» للنهائي، ويمرّر مدخلاً مشوَّهاً (fail-open). يُضاف يدوياً إلى `.claude/settings.json` — `install.py --claude` يطبع المقطع ولا يعدّل شيئاً.

## حدود معلنة
الحراس تحليل ساكن: لا تلتقط `eval` ولا `python -c` ولا سكربتاً يحذف من الداخل. القاعدة الصارمة تبقى في قانون الملفات الحصرية، والخطّاف شبكة أمان لا بديلاً عن الانضباط.
